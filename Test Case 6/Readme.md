6. Historical Reporting with Window Functions

Objective: Create historical reports comparing sales trends over time.
Steps:
1. Extract data from the sales table.
2. Use window functions like LAG() to calculate previous values.
3. Compare current and previous sales data for trend analysis.
Tasks:
- Use LAG() or LEAD() to calculate the previous period’s sales.
- Compute year-over-year or month-over-month growth.
